# Cowl - Front

REMOVAL/INSTALLATION

Remove the following:
* Windscreen stay
* Middle cowl
* Upper deflector
socket bolt (long)
[1]
* Plastic washer [2]
* Rubber washer
[3]

![Image page-001-img-01.jpg](images/page-001-img-01.jpg)

Move the screen
sliders [1] to the bottom
position.

Remove the following:
* Socket bolts [2]
* Trim clips [3]

Release the bosses [4]
from the grommets [5].

Remove the front cowl
[6].

Installation is in the
reverse order of
removal.

socket bolt (long):
